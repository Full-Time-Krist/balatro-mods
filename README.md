# balatro-mods

Моды для Balatro на [Steamodded](https://github.com/Steamodded/smods).

## Установка

Скопируйте нужные папки (`HeadStart`, `RuFill`, `MemSaver`) в папку модов
(`%AppData%\Balatro\Mods` на Windows). Нужны Steamodded и
[Lovely](https://github.com/ethangreen-dev/lovely-injector).

## HeadStart

Настраиваемые бонусы в начале каждого забега, на любой колоде: деньги, руки,
сбросы, размер руки, слоты джокеров и расходников, стартовые джокеры
выбранной редкости, спектральные карты, карты кода (Cryptid) и наборы ваучеров.
Всё настраивается в меню мода.

## RuFill

Русский перевод строк, которые другие моды оставили на английском. Перевод
лежит в `localization/ru.lua`. В `tools/` — скрипты для выгрузки строк,
проверки переменных `#n#` и сборки файла перевода.

## MemSaver (Экономия памяти)

Для больших сборок, которые не помещаются в оперативную память. Steamodded
при запуске загружает все картинки и звуки всех модов; с десятками модов это
больше тысячи текстур, и на 8 ГБ (особенно со встроенной графикой) игра
молча вылетает во время загрузки.

- Атласы загружаются при первой отрисовке, а не при запуске.
- В главном меню и в начале забега загруженные атласы выгружаются, снова
  подгружается только то, что на экране.
- Звуковые эффекты читаются с диска при первом проигрывании; файлы больше
  1 МБ проигрываются потоком. Музыка грузится как обычно.

Настроек нет. Возможна короткая подгрузка при первом показе новой карты.

## Curator (Куратор сборки)

Убирает из случайных пулов дубли — карты, повторяющие эффект карты из другого мода (`bans.lua`, 16 штук; в коллекции остаются, отключается в настройках мода) — и чинит межмодовые несовместимости (`fixes.lua`, `lovely.toml`).
`autotest.lua` — бот для проверки сборки: файл `curator_autotest_request` в папке сохранений запускает прогон (подсказки всех карт, розыгрыш рук с группами по 5 джокеров, применение каждого расходника), ошибки пишутся в `curator_autotest.log`, позиция — в `curator_autotest_state.lua`. Бот играет в текущем профиле: перед запуском сделайте бэкап сохранений.
